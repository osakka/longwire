# 0001 — The name is longwire

Status: accepted

## Context

The project needed a name that says what it does, is easy to say and spell, and doesn't collide. The product is one
Ethernet segment stretched between sites; it dials like a telephone; and it should be at home next to its sibling
project, hibr.

## Decision

The name is **longwire**, always lowercase, one word. A long wire is one cable stretched between sites, which is exactly
what the product does; it is also the simplest antenna there is, a strand of wire that reaches anywhere. Everything else
in the vocabulary comes from the telephone exchange: a node has a *number*, you *dial*, it *rings*, someone *picks up*,
and the *switchboard* connects the call and gets off the line ([BRAND](../BRAND.md)).

## Consequences

A web search at the time found no VPN or mesh project using the name. A trademark and domain search is still needed
before a public launch. The vocabulary is a commitment: the CLI, the docs, the desktop and the Android app all use the
same words, and "tunnel", "peer ID" and "mesh" stay out of the product.
